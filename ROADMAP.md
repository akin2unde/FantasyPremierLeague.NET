# Roadmap

- Add MongoDB, SQL Server, Redis, and distributed-cache manager-store examples.
- Add HTTP integration tests for automatic `401` refresh and retry.
- Add authentication tests using recorded, sanitized token responses.
- Add configurable resilience policies for transient upstream failures.
- Add response caching for stable public endpoints.
- Continue expanding typed models as the FPL API evolves.
- Publish NuGet prerelease packages after CI validation.
